# Customer Manager Application

A JavaFX desktop application designed for managing customer records with interactive form controls, dynamic table updates, and input validation.

## Features

- **Form Management**: Input customer names and select provinces using structured controls.
- **Dynamic TableView**: Displays added customers in real-time using JavaFX `ObservableList`.
- **Validation**: Ensures non-empty text fields and valid dropdown selections before submission.
- **Deletion Handling**: Confirmation alert popups when deleting records.
- **Keyboard Navigation**: Native accessibility with keyboard tab stops and control triggers.

## Tech Stack

- **Java**: Version 21
- **JavaFX**: Controls & FXML (Version 21)
- **Build Tool**: Gradle
